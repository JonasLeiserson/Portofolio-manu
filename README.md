# Manuel — Portfolio de viajes

Portfolio personal de viajes diseñado para reunir destinos, fotografías y experiencias en un recorrido visual.

El sitio presenta una portada, un mapa de destinos y páginas individuales para cada lugar visitado: Japón, Barcelona, Copenhagen, Abu Dhabi, Nueva York, México, Bariloche y Mar abierto.

## Tecnologías

- React 19
- TypeScript
- TanStack Start y TanStack Router
- Vite
- Tailwind CSS

## Requisitos

- Node.js
- npm

## Desarrollo local

Cloná el repositorio e instalá las dependencias:

```bash
git clone https://github.com/JonasLeiserson/Manuel-front-Portfolio.git
cd Manuel-front-Portfolio
npm install
npm run dev
```

Vite inicia el servidor de desarrollo y muestra en la terminal la dirección local para abrir el sitio.

## Comandos disponibles

| Comando | Descripción |
| --- | --- |
| `npm run dev` | Inicia el servidor de desarrollo |
| `npm run build` | Genera la compilación de producción |
| `npm run preview` | Previsualiza la compilación |
| `npm run lint` | Ejecuta ESLint |
| `npm test` | Ejecuta las pruebas |

## Organización del proyecto

- `src/routes/`: rutas y páginas de la aplicación.
- `src/components/`: componentes reutilizables de interfaz.
- `src/data/`: datos utilizados para construir las páginas.
- `src/assets/`: recursos estáticos y referencias a recursos del diseño.
- `public/`: archivos servidos directamente por la aplicación.
