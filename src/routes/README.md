# Páginas del portfolio

Las rutas se definen por archivo con TanStack Router. Cada página carga el diseño correspondiente desde `src/components/FigmaPage.tsx`.

| Archivo | Página |
| --- | --- |
| `index.tsx` | Inicio |
| `mapa.tsx` | Mapa de destinos |
| `japon.tsx` | Japón |
| `barcelona.tsx` | Barcelona |
| `copenhagen.tsx` | Copenhagen |
| `abu-dhabi.tsx` | Abu Dhabi |
| `new-york.tsx` | New York |
| `mexico.tsx` | México |
| `otros-rumbos.tsx` | Otros rumbos |
| `bariloche.tsx` | Bariloche |
| `mar-abierto.tsx` | Mar abierto |

La estructura visual, las coordenadas y las rotaciones de las fotografías están en `src/data/pages.ts`.
